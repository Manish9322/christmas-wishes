# Faceted Holiday Egg

**Faceted Holiday Egg** is an interactive monochromatic 3D holiday greeting experience that pairs sculptural geometry with smooth WebGL physics. Explore an asymmetrical polygon-faceted egg on the main route (`/`) or a spiral-banded spherical Christmas ornament at `/orb`—drag to rotate, scroll or pinch to zoom, and click to split the shell in two, releasing monochrome 3D confetti to reveal a `"Merry Christmas!"` greeting card with a smooth close-and-reset control.

The platform is built with a modern technology stack, including **Next.js**, **React**, **TypeScript**, **Three.js**, **Tailwind CSS**, **Motion**, and **Lucide React**, ensuring a highly performant, responsive, and engaging user experience.
